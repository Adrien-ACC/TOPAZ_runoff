This folder contains data files that are necessary for the code.

-In the folder 'river/auxiliary_files__glofas_v4_0', you will find the GloFAS auxiliary files for version 4.0 of GloFAS (necessary to compute river forcing). If you use a newer version of GloFAS, you'll have to download the new auxiliary files.

-In 'river/correction_files' you will find a NetCDF correction file for GloFAS data that can be used in the code. You can use this one (that uses years 2001-2019) or make your own (see technical documentation).

-In 'river/GloFAS_edit_files' you will find a CSV file with example of GloFAS edit file that you can use to change the position of an estuary (see technical documentation to find how to create this file with the graphical interface).

-In 'TOPAZ2' and 'TOPAZ5' you will find regional grid and depth files for TOPAZ. These are also necessary in the program to compute the river forcing file.
